# scrapshot-site

The Scrapshot website (GitHub Pages): home, privacy policy, terms of use, support.
Plain static HTML/CSS; fonts and images are self-hosted (no third-party requests).

Edit `build.py`, run `python3 build.py`, commit the generated `.html` files.

The privacy policy must match the game's data audit (`Docs/privacy-audit.md` in the game repo):
update both together, e.g. when an ad network is added.

Custom domain: see `docs/custom-domain.md`.

Fonts: Lilita One and Nunito, SIL Open Font License (see `assets/fonts/*-OFL.txt`).
